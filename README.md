# Oscillating Slotted Link Mechanism
Project developed for the Mechanics of Machines 2 exam - Automation Engineering
## Overview
This project analyzes the kinematics and transmission characteristics of an oscillating slotted-link mechanism, composed of a rotating crank, a sliding block, and an oscillating rocker with a slot in which the block moves.

## Objective
-	Verify that the crank can complete a full rotation based on the geometric constraints.
-	Perform position, velocity and acceleration analysis.
-	Calculate the transmission ratio between crank and rocker rotation.
-	Compute the balancing force F applied horizontally at point A of the rocker when a constant torque C = 1 Nm acts on the crank.
